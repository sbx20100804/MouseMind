# MouseMind 产品概要

## 一句话定义

MouseMind 是“鼠标上的快捷指令平台”：用应用上下文、鼠标手势和 AI，把重复的屏幕操作压缩成一次点击。

## 用户问题

1. 鼠标厂商驱动界面复杂，配置与具体设备绑定。
2. 同一侧键在不同软件中需要承担不同功能。
3. 翻译、总结、OCR 等操作需要复制、切换窗口、粘贴和再复制。
4. 宏工具通常只理解按键，不理解当前应用和选中内容。

## 产品原则

- **上下文优先**：动作由“当前在哪里、选中了什么”决定。
- **本地优先**：配置、日志和敏感文本默认留在本机。
- **可解释**：动作执行前后都有明确反馈，并可撤回。
- **渐进增强**：基础映射无需 AI；AI 是可选动作节点。
- **设备无关**：优先支持标准 XButton1/XButton2，而非绑定单一品牌。

## 关键用户流程

### 创建配置
选择应用 → 选择触发器 → 选择动作 → 测试 → 启用。

### 日常使用
切换前台应用 → MouseMind 自动激活匹配配置 → 用户按侧键 → 执行动作 → 显示轻提示。

### AI 文本动作
选中文字 → 触发鼠标动作 → 自动复制 → 调用处理器 → 写入剪贴板或浮窗展示。

## 数据模型

- Profile：名称、目标进程、颜色、启用状态、Mappings。
- Mapping：Trigger、Action、Description。
- Trigger：设备事件、按键、手势、修饰键。
- Action：类型、参数、执行策略、回滚策略。

## 成功指标

- 新用户 3 分钟内完成第一条映射。
- 日活用户每天触发至少 10 次动作。
- 常用工作流平均减少 3 次以上键鼠操作。
- 侧键监听不明显增加 CPU 占用，不影响原按键行为。
